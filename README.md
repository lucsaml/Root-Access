# Root Access (a minecraft modpack)
 it is just nothing :D
 this still in devlopment :P

Root Access is a modpack focused on technology, automation, and progression.

Starting with limited resources, the player evolves through different technological systems until achieving total control of the world.

The modpack combines advanced automation, intelligent storage, and integration between multiple mods, allowing for everything from simple factories to fully automated complex systems.

With support for additional dimensions and tools like Applied Energistics 2, Create, and CC: Tweaked, the goal is to allow the player to build, control, and expand their own "system" within Minecraft.

The more you evolve, the more control you have… until you reach true Root Access.
